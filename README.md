# Programming Fundamentals Final Project

This repository contains my final project for the Programming Fundamentals course.  
The project is a small interactive website built with **HTML**, **CSS**, and **JavaScript**.

## 📁 Project Files
- **index.html** – Main webpage of the final project  
- **/Docs** – Contains documentation and design notes  
- **/js** – Contains JavaScript used for the project  

## 🎯 Purpose of the Project
The goal of this final project was to show that I understand:
- Basic HTML page structure  
- Linking CSS and JavaScript  
- Creating user interaction  
- Organizing project files into a clean structure  

## 🚀 How to Run
1. Download the project folder  
2. Open **index.html** in any web browser  
3. Interact with the page and test the features  

## 📌 Notes
This project was completed as part of the **2nd semester coursework** at CVTC.  
It demonstrates fundamental programming concepts and clean project organization.
